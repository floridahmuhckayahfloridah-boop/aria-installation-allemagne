Installation :
1. Faites une copie de sauvegarde du fichier actuel.

3. Acceptez le remplacement du seul fichier indiqué ci-dessus.
4. Dans PowerShell, exécutez : npm run lint
5. Puis : npm run build
6. Lancez npm run dev et testez le chat sur smartphone et ordinateur.
